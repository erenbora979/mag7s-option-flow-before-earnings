## 1. Project Overview & Motivation
### Problem Statement
In financial markets, institutional investors ("smart money") often use the options market to hedge or speculate before major corporate events. This project investigates whether **Option Flow (Put/Call Volume)** observed immediately before an earnings announcement can predict the **post-earnings price direction** of the "Magnificent Seven" stocks (AAPL, MSFT, GOOGL, AMZN, NVDA, TSLA, META).

### Hypothesis
* **$H_0$:** Pre-earnings option flow has no statistical correlation with post-earnings price movement.
* **$H_1$:** Pre-earnings option flow (specifically Call/Put ratio and volume) is a significant predictor of the next day's price direction.

## 2. Dataset & Methodology
This project employs a **hybrid data strategy** to comply with the course requirement of "enriching public data".

### Data Sources
1.  **Stock Price Data (Real):**
    * **Source:** Yahoo Finance API (`yfinance`).
    * **Scope:** Daily OHLCV data for 7 tickers from Jan 2023 to Jan 2025.
2.  **Option Flow Data (Simulated/Enriched):**
    * **Constraint:** Proprietary option flow data (e.g., from *Unusual Whales*) is not publicly accessible via free APIs.
    * **Method:** A stochastic simulation engine was developed to generate synthetic option flow data (Call Volume, Put Volume, Sentiment Score). This simulation incorporates market microstructure rules (e.g., volume spikes on earnings days) to demonstrate the validity of the analysis pipeline.

## 4. Machine Learning Model
To test the hypothesis, we treated this as a **Binary Classification Problem**.

* **Target Variable:** `Next_Day_Move` (1 = Price Up, 0 = Price Down).
* **Features:** `Call_Volume`, `Put_Volume`, `Put_Call_Ratio`, `Option_Sentiment`, `Is_Earnings_Day`.
* **Model:** Random Forest Classifier (`n_estimators=100`).
